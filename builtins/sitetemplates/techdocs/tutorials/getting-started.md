# Getting started with {{title}}

In this tutorial you will go from nothing to a first working result with
{{title}}. It takes about fifteen minutes. You do not need any earlier
experience.

*This page is an example. It shows the shape of a good tutorial; replace the
steps with the real first run of your project.*

## Before you begin

Write down what the learner needs: a tool installed, an account, a folder to
work in. Keep it short, and link to a how-to guide if installing is a task on
its own.

## Step 1: Set up

Tell the learner exactly what to type, and what they should see afterwards.

```sh
mkdir first-project
cd first-project
```

You should now be inside an empty folder called `first-project`.

## Step 2: Make something small

Each step makes one change and shows its result. Avoid choices here: if there
are two ways, pick the better one and use it.

```yaml
name: first-project
version: 0.1.0
```

Save the file. You now have a project with a name and a version.

## Step 3: Check that it works

End with a check the learner can run, so they know they succeeded.

If something is wrong, say how to tell and what to do next. A learner who is
stuck on a tutorial often gives up for good.
