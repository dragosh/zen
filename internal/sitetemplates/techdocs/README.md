# {{title}}

Welcome to the documentation for {{title}}. It is split into four parts,
because people come to documentation for four different reasons. Pick the one
that matches what you need right now.

| You want to | Go to | It gives you |
|---|---|---|
| learn by doing, as a beginner | [Tutorials](tutorials/index.md) | a guided lesson that always works |
| get a job done | [How-to guides](how-to/index.md) | steps for one real task |
| check a fact | [Reference](reference/index.md) | dry, complete and exact descriptions |
| understand why | [Explanation](explanation/index.md) | background, reasons and trade-offs |

Keeping the four apart is what makes the pages easy to write and easy to find.
The idea comes from the [Diátaxis](https://diataxis.fr) framework, which is
worth a read before you add many pages.

Documentation by {{author}}. This home page, and every other page, is plain
markdown: open any file in your editor, or press Edit in zen.
