# Tutorials

Lessons that take a newcomer by the hand. Each one is a short journey with a
clear start and a result the learner can see.

A tutorial teaches by doing. It does not explain every detail on the way, and it
does not offer choices. If a reader asks "why", link to an explanation; if they
ask "what are my options", link to the reference.

## What belongs here

- A first run that ends in something that works.
- Steps in a fixed order, each with a visible result.
- A promise at the top: what the reader will have at the end.
