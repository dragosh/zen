Install

zen is a single application. Open a folder and it turns the markdown inside into a small site you can read and edit. See Usage for the next step.

From a terminal

cd my-docs
zen
Everything is rendered locally. Nothing leaves your machine.

Use zen edit README.md to open the editor directly.
