# Keyboard shortcuts

## Main window

| Keys | Action |
|---|---|
| <kbd>⌘N</kbd> | new page |
| <kbd>⌘O</kbd> | open a folder |
| <kbd>⌘P</kbd> | print the page |
| <kbd>⌘E</kbd> | edit the page |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | back / forward |
| <kbd>⌘\</kbd> | show or hide the sidebar |
| <kbd>⌘,</kbd> | settings, from any window (<kbd>Esc</kbd> goes back) |
| <kbd>⌘W</kbd> | close the window |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | move in the sidebar, close and open branches |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | move the selected page up / down among its siblings in the sidebar |
| <kbd>⇧F10</kbd> or the menu key | the selected page's menu in the sidebar |

## Editor window

| Keys | Action |
|---|---|
| <kbd>⌘S</kbd> | save |
| <kbd>⌘B</kbd> / <kbd>⌘I</kbd> / <kbd>⌘K</kbd> | bold / italic / link |
| <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> | indent / outdent |
| <kbd>Esc</kbd> | done |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | undo / redo |
| <kbd>⌘W</kbd> | close (asks first if there are unsaved changes) |
