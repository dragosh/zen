# Hello, zen

Plain files age well. A folder of markdown opens in any editor, travels in any
backup and reads the same in ten years.

zen is a quiet place to read that folder. It adds a sidebar built from your
links, a reading view that stays out of the way, and a spelling check that flags
a mistake while you write.

## Why a blog in a folder

A post is a page with a date. Nothing else is needed: the layout of the folder
turns it into a post, and the sidebar puts the posts in order.
