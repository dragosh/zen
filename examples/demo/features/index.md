# Features

What this build of Zenmark can do, one page each, in the order of the build.

| Feature | What it does |
|---|---|
| [Reader](reader.md) | shows a page, keeps it up to date and renders all the markdown |
| [Navigation](navigation.md) | the sidebar, links and breadcrumbs built from your pages |
| [Find](find.md) | looks for text in the open page with <kbd>⌘F</kbd> |
| [Editor](editor.md) | edits a page in its own window, and adds new pages |
| [Inspector](inspector.md) | tells you about the page: Page Info and Problems |
| [Print](printing.md) | prints a page or saves it as a PDF |
| [Export](export.md) | turns the folder into a website or one PDF |
| [Developer](developer.md) | adds the Console and Build tabs to the Inspector |

Keyboard keys for all of them are in [Keyboard shortcuts](../intro/shortcuts.md).
