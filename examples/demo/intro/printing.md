# Print a page

**File › Print Page…** (<kbd>⌘P</kbd>) prints the page you are reading
through the macOS print panel, so **Save as PDF** is in it too. The page prints
as it looks, in black on white whatever the app's theme. The sidebar, top bar
and buttons are left out; what they show stays, such as quiz questions and the
answers given so far.

- Headings stay with the text after them, and code blocks, tables and
  diagrams are not split where they fit on a page.
- Long code lines wrap.
- Links to other sites print their address after the text, like
  [the markdown guide](https://commonmark.org/help/).
  Links to other pages print as plain text.
- Details blocks print open.

<details>
<summary>What about layouts?</summary>

A layout keeps its own print rules: **handout** prints just its sheet,
**slides** print one slide per page, and a **course** prints all its steps one
after another. The Layouts part of this guide shows each of them.

</details>
