# Zen in five slides

A quiet place to read and write markdown.

Note: Welcome everyone. Keep this one short.

---

## Why zen

- Your notes stay plain markdown files
- Pages render fast and look calm
- Plugins add diagrams, slides and courses

Note: Mention that nothing leaves the Mac.

---

## Open a folder

1. Choose File, then Open Folder
2. Pick any folder with markdown files
3. Read pages from the sidebar

---

## Make it yours

Switch plugins on or off in the settings. A page picks a layout in its frontmatter:

```yaml
layout: slides
layoutOptions: { ratio: "4:3" }
```

---

## Keys to remember

- Arrow keys, Space, Page Up and Page Down move between slides
- Home and End jump to the first and last slide
- O shows all slides, F fills the screen
- P prints one slide per page
